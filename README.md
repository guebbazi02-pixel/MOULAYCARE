# MOULAYCARE — تطبيق أندرويد لإدارة العيادات الصغيرة

تطبيق لإدارة المرضى والمواعيد، يعمل **دون إنترنت**، وكل البيانات محفوظة على الهاتف نفسه.

## المميزات
- **ملفات المرضى:** رقم ملف تلقائي (MC-0001)، والبيانات الشخصية، وفصيلة الدم، والوزن والطول، والحساسية (تظهر كتنبيه أحمر)، والأمراض المزمنة، والأدوية، والسوابق، والتأمين.
- **سجل الزيارات:** الشكوى، والعلامات الحيوية (الضغط، الحرارة، النبض، السكر، الوزن)، والتشخيص، والعلاج/الوصفة، وموعد المتابعة.
- **إرفاق الملفات:** صور التحاليل والأشعة والوصفات والتقارير (التقاط بالكاميرا أو اختيار صورة/PDF)، مع إمكانية المشاركة والفتح.
- **المواعيد:** شريط أسبوعي، والأوقات المتاحة حسب ساعات العمل، والتنبيه عند تعارض المواعيد، والحالات (مجدول، مؤكد، في الانتظار، مكتمل، لم يحضر، ملغي).
- **التنبيهات:** إشعارات أندرويد قبل الموعد وعند حلوله (تعمل والتطبيق مغلق، وبعد إعادة تشغيل الهاتف)، وملخص صباحي، ومركز تنبيهات للمواعيد الفائتة ومواعيد الغد.
- **تذكير المرضى عبر واتساب** برسالة جاهزة، والاتصال المباشر بالمريض.
- **نسخة احتياطية واستعادتها**، وبيانات تجريبية للتعرّف على التطبيق.

## الحصول على ملف APK

### الطريقة 1: Android Studio (على الحاسوب)
1. ثبّت [Android Studio](https://developer.android.com/studio).
2. افتح هذا المجلد: **File → Open → MOULAYCARE**، وانتظر حتى ينتهي تحميل Gradle.
3. من القائمة: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`. انقله إلى الهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).
   أو وصّل الهاتف بالحاسوب واضغط ▶ Run.

### الطريقة 2: GitHub (بدون تثبيت أي برنامج)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه محتويات هذا المجلد.
2. سيعمل البناء تلقائياً في تبويب **Actions**، ويستغرق حوالي 3–5 دقائق.
3. افتح آخر عملية بناء ← **Artifacts** ← حمّل **MOULAYCARE-apk** وفكّ ضغطه وثبّته على الهاتف.

## بنية المشروع
```
app/src/main/
├── assets/www/          واجهة التطبيق (index.html, style.css, app.js)
├── java/com/moulaycare/app/
│   ├── MainActivity.kt  الشاشة الرئيسية + الجسر مع أندرويد (ملفات، كاميرا، واتساب، مشاركة)
│   └── Reminders.kt     جدولة الإشعارات + إعادة الجدولة بعد إعادة التشغيل
└── res/                 الأيقونة والألوان
```

## ملاحظات

- في أندرويد 13 وما بعده، وافق على صلاحية الإشعارات عند أول تشغيل. ولتذكيرات دقيقة في وقتها: الإعدادات ← صلاحية الإشعارات.
- للنشر على Google Play، أنشئ نسخة Release موقّعة: **Build → Generate Signed Bundle / APK**.
